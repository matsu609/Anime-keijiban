# アニメ掲示板

関東の地上波アニメの放送カレンダーと、話数ごとの匿名実況・感想掲示板です。日本時間で今日・明日の放送と今期の作品一覧を表示します。

- しょぼいカレンダーとの同期は毎日16:07〜16:37（日本時間）に最大1回です。放送枠は1回でまとめて取得し、作品情報は D1 の保存分を7日間再利用します。新規・期限切れの作品情報は100件ずつ取得します。閲覧時は D1 を参照します。作品IDと話数が同じ枠は同じスレッドへ案内します。話数なしの枠は放送枠ごとのスレッドになります。
- 今期一覧は関東の対象局で取得できた放送枠から、作品の初回放送・終了時期を使って集計します。放送を確認できた作品は同じクール中は保持します。
- 投稿は D1 に保存され、スレッドを開いている間は15秒ごとに新着を確認します。「人気スレッド」は直近7日間のこの掲示板の投稿数順です。
- 表示名は固定の「名無し」です。連投制限に日単位のハッシュを利用し、コメント API では公開しません。

## 開発

Node.js 24 で動作確認しています。

```sh
npm ci
npm run db:local
npm test
npm run dev
```

Cloudflare の Workers Builds で GitHub の `main` を接続し、運用する D1 を `DB` に割り当てます。初回は `npm run db:remote` でスキーマを適用します。Worker のデプロイコマンドは `npm run deploy` です。

番組データは [しょぼいカレンダー](https://cal.syoboi.jp/) を利用しています。アクセス先は [しょぼいカレンダー JSON API](https://cal.syoboi.jp/json.php) で、`ProgramByDate` と `TitleShort` を利用します。上流が一時的に失敗した場合は前回の番組表を保持します。手順と操作の検証にはテストデータを利用し、公開番組表にテスト作品を表示する設定はありません。

## 人が集まる理由の検証

初期仮説は「今夜何が放送されるかを確認しに来た人が、放送時刻の前後に同じ話のスレッドを開く」です。まず作品を絞って、運営者が一つの問いを実際に投稿し、会話が始まるかを見る小さな実験を想定しています。

放送スケジュールを基準に、放送前・放送中・放送後のスレッド閲覧、初回投稿、返信が続いた話を比べると、リアタイ実況と視聴後の感想のどちらに需要があるかを判断できます。現在の実装では投稿数を表示し、閲覧計測や外部の話題収集は行いません。
