# 企画メモ：アニメを語り、制作現場を応援できる掲示板

## 企画の軸

好きなアニメを語ることを入口に、ファンが作品の作り手を知り、確認できる支援先へ進める場所にする。掲示板での交流から、ファン・クリエイター・制作会社の継続的なつながりをつくる。

**最初に試す導線**

番組表 → 話数別の実況・考察 → 作品のスタッフ名鑑 → 担当者の別作品・公開プロフィール → 公式の支援先

| 画面 | 役割 |
|---|---|
| 作品・議論 | 作品別・話数別のスレッド、考察、実況、ネタバレ表示の設定 |
| 制作現場 | スタッフ名鑑、報酬・労働環境の統計、業界ニュース、お金の流れ |
| 応援する | 公式支援、スタジオ公認の募集企画、求人 |

## 追加機能7案

| 機能 | 内容と狙い |
|---|---|
| ① 制作現場への直接支援 | 作品ページからスタジオ・アニメーターの公式支援窓口へ案内。将来は制作会社公認の支援企画も掲載する。 |
| ② 制作スタッフ・スタジオ名鑑 | 監督、原画、背景美術、制作会社などのクレジットを作品ごとに掲載。担当作品と公開プロフィールをたどれるようにする。 |
| ③ 報酬・労働環境データベース | 現役の作り手から職種・報酬・労働時間を匿名かつ任意で募る。十分な回答がある範囲で集計し、新人の仕事選びや報酬交渉に役立てる。 |
| ④ お金の流れの可視化 | 制作会社・製作委員会・配信事業者の関係を図解。出資・権利関係は公開資料で確認できる範囲を表示し、購入や支援の受取先が分かるようにする。 |
| ⑤ 業界関係者の認証付き掲示板 | 一般ファンは匿名のまま参加。希望する関係者は非公開の本人確認を経て認証表示を選べる。制作現場への質問企画も候補にする。 |
| ⑥ 制作の求人・仕事募集 | 制作会社とアニメーターをつなぎ、報酬、契約条件、納期、支払条件を募集時に明示する。制作会社向けの有料掲載を収益案とする。 |
| ⑦ スタジオのクラウドファンディング | 機材購入、新人育成、オリジナル作品などの資金募集。受取先、支援額、使途、進捗を公開する。 |

## 実装順と事業仮説

| 段階 | 実装・検証 | 収益化候補 |
|---|---|---|
| 1 | 既存の話数別スレッドを作品別にまとめ、ネタバレ制御とスタッフ名鑑を追加。まず少数作品の公開クレジットで、議論から名鑑へ進むかを見る。 | 広告・有料会員 |
| 2 | 受取先を確認した公式支援リンクを掲載。制作現場情報と関係者認証を加え、名鑑から支援先への遷移や質問企画への参加を検証する。リンク遷移と支援成立は別々に扱う。 | 企業協賛 |
| 3 | 制作会社と作り手の参加を確かめた上で、求人と公認の資金募集を検討する。報酬統計は回答協力と匿名性を確保できる段階で進める。 | 求人掲載料・決済手数料 |

## 開発前に確認すること

- 動画の論点は、市場の成長と制作現場の収益・報酬の伸びには差が生じ得ること。制作会社ごとに権利収入や出資の有無が異なる。帝国データバンクの調査では、2025年の制作会社のうち34.6%が赤字、45.7%が増益だった。[帝国データバンク「アニメ制作市場」動向調査2026](https://www.tdb.co.jp/report/industry/20260819-animation25y/)
- 支援リンクは公式性、窓口の運営者、実際の受取先、確認できた範囲を表示する。
- 報酬統計は少数の区分を公開せず、複数条件の組み合わせによる再特定も防ぐ。本人確認情報の公開範囲と保管方法は認証機能の設計時に定める。
- サイト内で資金を受け付ける前に、受取人の本人確認、募集主体の権利・権限、決済と必要な法令対応を確認する。
